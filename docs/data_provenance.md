# Data provenance

## Replogle Perturb-seq

Processed K562 and RPE1 Perturb-seq data are obtained from scPertEval/Replogle et al. 2022.

The SRA BioProject PRJNA831566 contains only transcriptomic Perturb-seq libraries. Inspection of all 7,883 runs showed:

- library_strategy: OTHER
- library_source: TRANSCRIPTOMIC
- library_selection: size fractionation

The pooled K562/RPE1 growth-screen sequencing described in Replogle et al. Figure S1 is therefore not contained in this BioProject.

For the Phase 0 pilot, functional fitness measurements will be obtained from independent public CRISPR fitness screens and treated as orthogonal validation rather than matched measurements from the Perturb-seq experiment.
